# Store/onpremise-dev-primary

This directory houses the on-premise PostgreSQL development cluster (ONPREMISE-DEV-PRIMARY) generated by `npm run ops:bootstrap-onpremise-dev`. The script writes runtime artifacts (cluster data dir, snapshots, metadata, and the connection string file) that stay ignored by git via `.gitignore` so the repository never captures secrets or binary data.

When refreshing the offline mirror, the script writes the active connection string to `local-url.txt`; export `DATABASE_ONPREMISE_DEV_PRIMARY` so Prisma can treat the on-premise cluster as a fallback candidate. See `docs/database-naming-schema.md` for complete canonical naming reference.
