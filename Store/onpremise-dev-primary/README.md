# Store/db

This directory houses the local Postgres fallback cluster generated by `npm run ops:bootstrap-local-db`. The script writes runtime artifacts (cluster data dir, snapshots, metadata, and the connection string file) that stay ignored by git via `.gitignore` so the repository never captures secrets or binary data.

When refreshing the offline mirror, the script writes the active connection string to `local-url.txt`; point `DATABASE_LOCAL_URL_FILE` at that path or export `DATABASE_LOCAL_URL` so Prisma can treat the local cluster as a fallback candidate.
