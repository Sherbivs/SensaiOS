## Command Documentation

### Command 1: `/ops homestead:integrity`

**Purpose:** Display latest IntegrityReport for specified guild with detailed orphan/ghost breakdown.

**Parameters:**
- `guild_id` (required, string) — Discord guild ID to query

**Behavior:**
1. Reads `Store/homestead-integrity/` directory (Render: `/Store`, local: `./Store`)
2. Finds latest JSON report matching `{guild_id}-*.json` pattern
3. Parses IntegrityReport with Date conversions
4. Displays formatted summary with emojis and color-coded issue rate
5. Shows top 5 orphans and ghosts with details
6. Provides report file path and cleanup instructions

**Output Format:**
```
🏠 Homestead Integrity Report

📊 Summary:
   • Total Homesteads: {total}
   • ✅ Verified: {verified}
   • ❓ Unverified: {unverified}
   • 🚨 Orphans (DB but no channel): {orphans}
   • 👻 Ghosts (Channel but no DB): {ghosts}
   • Issue Rate: {rate}% {color_indicator}

🚨 Orphaned Channels (Top 5):
   1. User: {userId} | Channel: {channelId} | Created: {timestamp}
   ...

👻 Ghost Channels (Top 5):
   1. Name: {name} | ID: {id} | Created: {timestamp}
   ...

📄 Report: {file_path}
ℹ️  To cleanup orphans: /ops homestead:cleanup {guild_id} dry_run:True
```

**Issue Rate Color Coding:**
- 🟢 Green: <2% issues (healthy)
- 🟡 Yellow: 2-5% issues (warning)
- 🔴 Red: >5% issues (critical - triggers Phase 3.4 alerts)

**Error Handling:**
- No reports found → User-friendly message
- File read errors → Logged to `errorTracker` with HOMESTEAD category
- JSON parse errors → Error message with troubleshooting hint

**Example Usage:**
```
/ops homestead:integrity 123456789012345678
```

### Command 2: `/ops homestead:cleanup`

**Purpose:** Mark orphaned homesteads as 'deleted' in database with SOC 2 compliant audit logging.

**Parameters:**
- `guild_id` (required, string) — Discord guild ID to cleanup
- `dry_run` (optional, boolean, default: false) — Preview changes without committing

**Behavior:**
1. Loads latest IntegrityReport via `getLatestIntegrityReport()`
2. If dry-run mode: Returns orphan list without database modifications
3. If live mode:
   - Initializes `ImmutableAuditService` with HMAC secret and chain ID
   - Iterates through orphanList
   - Updates Prisma: `homesteadChannel.status = 'deleted'`
   - Appends audit entry for each cleanup action
   - Tracks errors per-orphan with rollback isolation
4. Returns CleanupResult with statistics

**Output Format (Dry-Run):**
```
🧪 Cleanup Preview (DRY RUN)

📊 Results:
   • Orphans Found: {count}
   • Would Mark Deleted: {count}

🚨 Orphans to cleanup:
   1. User: {userId} | Channel: {channelId}
   ...

ℹ️  Run with dry_run:False to apply changes
```

**Output Format (Live):**
```
✅ Cleanup Complete

📊 Results:
   • Orphans Found: {count}
   • Marked Deleted: {count}
   • Failed: {count}

🚨 Cleaned orphans:
   1. User: {userId} | Channel: {channelId} | ✅ Deleted

❌ Errors:
   • {error_message_1}
   • {error_message_2}

📝 All cleanup actions logged to ImmutableAuditService
```

**Audit Logging:**
Each cleanup action creates an audit entry:
```typescript
{
  action: 'homestead.orphaned.cleanup',
  actor: 'ops-admin-command',
  target: userId,
  timestamp: Date,
  metadata: {
    orphanId: string,
    guildId: string,
    channelId: string,
    cleanupReason: 'orphaned-no-discord-channel',
    previousStatus: 'active',
    newStatus: 'deleted',
  }
}
```

**Error Handling:**
- No reports found → User-friendly message
- No orphans found → Success message (nothing to cleanup)
- Per-orphan errors → Logged individually, don't block other orphans
- Database errors → Tracked in `errorTracker` with HOMESTEAD category
- Audit service errors → Cleanup continues, error logged

**Example Usage:**
```
# Preview changes
/ops homestead:cleanup 123456789012345678 dry_run:True

# Apply changes
/ops homestead:cleanup 123456789012345678 dry_run:False
```

## Technical Implementation

### Helper Functions

#### `getLatestIntegrityReport(guildId: string): Promise<IntegrityReport | null>`

**Purpose:** Read and parse latest IntegrityReport JSON file for specified guild.

**Implementation (55 lines):**
```typescript
async function getLatestIntegrityReport(guildId: string): Promise<IntegrityReport | null> {
  try {
    // Determine reports directory (Render vs local)
    const reportsDir = process.env.RENDER 
      ? '/Store/homestead-integrity'
      : './Store/homestead-integrity';

    // Read directory and filter by guild ID
    const files = await fs.readdir(reportsDir);
    const guildFiles = files
      .filter(f => f.startsWith(`${guildId}-`) && f.endsWith('.json'))
      .sort()
      .reverse(); // Most recent first

    if (guildFiles.length === 0) {
      return null;
    }

    // Read and parse latest file
    const latestFile = path.join(reportsDir, guildFiles[0]);
    const content = await fs.readFile(latestFile, 'utf-8');
    const data = JSON.parse(content);

    // Convert ISO date strings to Date objects
    return {
      ...data,
      timestamp: new Date(data.timestamp),
      orphanList: data.orphanList.map(o => ({
        ...o,
        createdAt: new Date(o.createdAt),
      })),
      ghostList: data.ghostList.map(g => ({
        ...g,
        createdAt: new Date(g.createdAt),
      })),
    };
  } catch (err) {
    log.error('Failed to read IntegrityReport', { guildId, error: getErrorMessage(err) });
    return null;
  }
}
```

**Error Handling:**
- Directory not found → Returns null (graceful degradation)
- File read errors → Logged and returns null
- JSON parse errors → Logged and returns null

#### `cleanupOrphanedHomesteads(guildId: string, dryRun: boolean): Promise<CleanupResult>`

**Purpose:** Mark orphaned homesteads as deleted with audit logging.

**Implementation (80 lines):**
```typescript
async function cleanupOrphanedHomesteads(
  guildId: string,
  dryRun: boolean
): Promise<CleanupResult> {
  // Load latest report
  const report = await getLatestIntegrityReport(guildId);
  
  if (!report) {
    return { orphansFound: 0, markedDeleted: 0, failed: 0, orphans: [], errors: [] };
  }

  const orphans = report.orphanList;
  
  // Dry-run mode: Return preview
  if (dryRun) {
    return {
      orphansFound: orphans.length,
      markedDeleted: orphans.length,
      failed: 0,
      orphans: orphans.map(o => ({ id: o.id, userId: o.userId, channelId: o.channelId })),
      errors: [],
    };
  }

  // Live mode: Initialize audit service
  const auditService = new ImmutableAuditService({
    hmacSecret: process.env.AUDIT_HMAC_SECRET || 'default-secret',
    chainId: 'homestead-operations',
  });
  await auditService.initialize();

  const result: CleanupResult = {
    orphansFound: orphans.length,
    markedDeleted: 0,
    failed: 0,
    orphans: [],
    errors: [],
  };

  // Process each orphan
  for (const orphan of orphans) {
    try {
      // Update database
      await prisma.homesteadChannel.update({
        where: { id: orphan.id },
        data: { status: 'deleted' },
      });

      // Log to audit service
      await auditService.append({
        action: 'homestead.orphaned.cleanup',
        actor: 'ops-admin-command',
        target: orphan.userId,
        timestamp: new Date(),
        metadata: {
          orphanId: orphan.id,
          guildId: guildId,
          channelId: orphan.channelId,
          cleanupReason: 'orphaned-no-discord-channel',
          previousStatus: 'active',
          newStatus: 'deleted',
        },
      });

      result.markedDeleted++;
      result.orphans.push({ id: orphan.id, userId: orphan.userId, channelId: orphan.channelId });
    } catch (err) {
      result.failed++;
      result.errors.push(`Failed to cleanup orphan ${orphan.id}: ${getErrorMessage(err)}`);
      
      // Log error but continue processing
      log.error('Orphan cleanup failed', {
        orphanId: orphan.id,
        userId: orphan.userId,
        error: getErrorMessage(err),
      });
    }
  }

  return result;
}
```

**Key Features:**
- **Per-Orphan Transactions:** Individual failures don't block others
- **Audit Logging:** Every cleanup action logged for compliance
- **Error Isolation:** Try-catch per orphan with detailed error tracking
- **Statistics:** Comprehensive result tracking (found, deleted, failed)
